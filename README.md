# Dark Colony Remaster

Official project showcase for an independent native macOS restoration of Dark Colony (1997), with ORIGINAL and REMASTER editions.

Visit the website: https://gregorymc86.github.io/DarkColonyRemaster/

Gameplay screenshots and synchronized comparisons are rendered by the project. ORIGINAL is the classic mode of the new engine, not captured footage of the original executable. No game binaries, game data, or playable download are distributed in this repository.

The project is in development. We would welcome contact from original creators, former team members, or anyone who can help identify the appropriate contacts to discuss a possible release. Please open a GitHub issue.
